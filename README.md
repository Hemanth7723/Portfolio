# Portfolio

A clean, minimal, and responsive personal portfolio template to showcase projects, skills, and contact information with a calm, modern aesthetic.

---

✨ Highlights

- Lightweight and responsive layout
- Styles authored in SCSS and compiled to CSS
- Minimal JavaScript for smooth, optional interactions
- Easy to customize and deploy

---

🛠️ Built with

- HTML5
- SCSS & CSS
- JavaScript (optional)

---

⚡ Quick start

1. Clone the repository:

   git clone https://github.com/Hemanth7723/Portfolio.git

2. Open locally:

   - Open index.html in your browser, or
   - Serve with a static server: `npx serve .` or `python -m http.server`

3. If you use SCSS, recompile to CSS after making style changes.

---

🎨 Customization

- Change colors and typography via the SCSS variables.
- Modify or reorder sections (About, Projects, Contact) in the HTML.
- Optimize and replace images for faster loading.
